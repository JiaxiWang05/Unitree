Brio 怎么装进头部（从机器人左侧看，前方在右）

这是示意图，头部内部画得很简化，支架画的是大致形状；准确的样子见 可以转动的 3D 模型。支架是试装件，还没在机器人上装过。先用 PLA 打一个比一下。机器人关机，坐着或挂在吊架上。

要准备的东西

  • 打印好的支架：head_brio_mount_print.stl（先 PLA 试装，正式用 PETG）
  • 2 颗 M4×16 螺丝
  • 1 颗 ¼"-20 × 5/8" 内六角螺丝 + 1 个 M6 垫片，3/16" 内六角扳手
  • 直角 USB-C 转接头，凸出相机背面不超过 13 mm（直插头有 35 mm 长，相机后面放不下）
  • 2 根小扎带

装好以后怎么用

  1. USB-C 线插到脖子后面板的 USB-C 口，开机，登录机器人。
  2. 先停服务，跑自检。看 camera 一行是不是认到 Brio，depth 一行是不是还是 PASS（头部深度相机没被挡住）： 
    cd ~/g1-greeter && systemctl --user stop g1-greeter
.venv/bin/python -m greeter --check
  3. 相机换了位置，一定要重新校准距离。面朝机器人，依次站到 1、2、3 m 的记号上： 
    .venv/bin/python -m greeter.robot.calibrate --stand-at 1 2 3
  4. 重新启动服务： 
    systemctl --user start g1-greeter

如果 depth 变成 WARN 或 FAIL，说明支架或相机挡住了深度相机。程序会改用摄像头估计站位区域，可以继续用，但请把那一行发给我。拆下：先松 ¼" 螺丝取下相机，再拧掉两颗 M4。文件和说明在 hardware/head_brio_mount。
