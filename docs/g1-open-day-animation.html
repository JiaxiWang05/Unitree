How it works

  1. See

    A webcam on the robot's chest watches the people in front of it.

  2. Understand

    Software on the robot finds each person and works out how far away they are, whether they face the robot and whether they wear green.

  3. Decide

    Simple rules decide when to invite someone, when to listen and when to stop: the steps above.

  4. Talk

    What the visitor says, with a camera picture, goes to an AI voice model online, which answers out loud through the robot's speaker.

  5. Check the spot

    A depth camera in the robot's head checks whether someone is standing on the talk spot, so anyone can start a chat there.

Safety and privacy: the program has no movement commands at all, so the robot cannot move its arms or walk. It does not recognise faces, and it only ever talks about clothes and objects.

Where things stand

Done

  • The software is written and passes 148 automated tests on a laptop, with the robot, camera and AI replaced by stand-ins
  • Webcam (Logitech Brio 4K) and cable bought
  • Chest bracket designed, checked against the robot's 3D model, and test-printed
  • Code and guides on GitHub, with this public page

Next, on the robot

  • Test the robot's own microphone; decide whether an extra one is needed
  • Install the software on the robot and run its self-test
  • Run a full visit with a lab webcam, then fit the Brio on the bracket
  • Decide: invite anyone, or only people in green

Not yet known

  • How fast it answers and how well it hears in a noisy hall
  • Whether the head's depth camera can be used alongside the robot's own software
  • How visitors react: the paper plan covers this study
