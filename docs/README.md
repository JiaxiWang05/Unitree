# Outputs

| File | What it is |
|---|---|
| `mic-camera-guide.html` | Procurement guide: which webcam and microphone to use on the G1 EDU+, the robot's ports and power, how to use the built-in mic, and the chest mount. Open it in a browser |
| `test-results.txt` | Output of the test suite (`pytest -v`) on a laptop, with the robot, camera and cloud services replaced by stand-ins |

The 3D-printable chest bracket for the webcam is in [`hardware/brio_chest_mount`](../hardware/brio_chest_mount/README.md).
